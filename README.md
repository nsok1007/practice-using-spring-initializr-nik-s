## Spring Boot Workflow
1. Create new GitHub repository
2. Run Spring Initializr [(start.spring.io)](start.spring.io)
3. Unzip the generated package
4. Click the pom.xml file in the project directory and open it in IntelliJ to open the project
5. Run Main class file (src-main-java-com.example.myproject-MyProjectApplication)
6. Use the command **git remote add origin** in the terminal to link your local repository (current project) to the a remote repository (see Step 1)
7. Commit changes to local repo using the in-built IntelliJ feature
8. Use the command **git push -u origin main** to push your local repository changes to the remote repository
